# Icons v2: new metro train markers and bus markers
Objective: use the two new sets the user added to `statics/`: `map-trains-v2/` (prettier metro trains) and `map-buses/` (top-down buses).
Branch: feat/icons-v2 (from main after the bus merge) · Test runner: macOS CI (assets and views); no Foundation-only code.
Status: the user said "he añadido mas iconitos, tanto para los metros (mas bonito) como para los autobuses" (2026-10-30); applied the same way as the first icon set.

## Facts
- `map-trains-v2/<line>@3x.png` are 216x96 px (render 42 x 18.67 pt, aspect 72:32), cab facing east, anchor center; same 11 line keys as `map-trains/` (l1 l2 l3 l4 l5 l9n l9s l10n l10s l11 fm).
- `map-buses/{standard,articulated,electric}-{red,blue,green,amber}` SVG + @3x PNG: standard and electric 54x32 (render 42 x 24.9 pt), articulated 64x32; facing east, anchor center. The README says electric and articulated variants must only be used when actual data supports them. The TMB iBus API exposes NO vehicle model, articulated flag or fuel type (documented fields: `temps_arribada`, `id_bus`; live adds `info_bus.accessibilitat`), so only the STANDARD silhouette is used.
- Each bus SVG has exactly one body colour (the `rect x=8 y=10 width=38 height=12` fill: red `#E53945`, blue `#168AC4`, green `#22A477`, amber `#ECA82B`). The 115 TMB bus lines use only 8 line colours (`COLOR_LINIA`): 003888, 6AB023, 937500, DA291C, 93107E, 010101, DF2228, 076AB3.

## Specs
- S1 Metro trains. The `train-<line>` imagesets are regenerated from `map-trains-v2` (same names, so call sites keep working). Map markers render at 42 x 18.67 pt instead of 36 x 30; the Xarxa overlay uses the same size, rotated 90 / -90 as before. Marker offsets (label below) are adjusted to the new height.
- S2 Bus markers. New imagesets `bus-<hex>` (hex lower case, e.g. `bus-003888`) for each of the 8 colours plus `bus-default` (blue body `#168AC4`), generated by recolouring the body fill of `map-buses/standard-blue.svg` to `#<COLOR_LINIA>` before rendering to PNG @3x (`rsvg-convert -w 162`, 54 px x 3). `BusMapScreen`'s `BusMarker` becomes this image (42 x 24.9 pt, heading rotation as now `heading - 90 - cameraHeading`, direction opacity as now); the line name stays visible as a small unrotated chip (`.caption2.bold`, line colour background, text colour `textColorHex`, capsule) above the bus, and the destination label (zoomed in only) keeps its place below. The Xarxa bus markers use the same image rotated 90 / -90 by direction, 42 x 24.9 pt, no name chip.
- S3 Fallback. Asset name = `bus-` + lower-case `colorHex` when that imageset exists (`UIImage(named:)` non-nil), else `bus-default`.
- S4 Tests. `AssetCatalogTests` checks `bus-default` and the 8 colour imagesets and that every `train-<line>` image is 216x96 px.
- S5 Out of scope: articulated and electric bus markers, fleet data, the old `map-trains` set (kept in statics, unused).
