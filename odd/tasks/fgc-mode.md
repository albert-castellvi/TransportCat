# FGC mode
Objective: add Ferrocarrils de la Generalitat de Catalunya (FGC) as a third mode with live GPS trains, built on a shared map-layer value model the future global mode will compose.
Branch: `feat/fgc-mode`. Delivery: ask-on-risk, work-unit commits, one PR. Test runner: XCTest in CI (`Generate project and run tests (simulator)`); Core-only logic also runs in the local Linux SwiftPM harness (engram: "Local Linux swift test loop").

## Specs
- S1 Data source. FGC open data portal, no key: `https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/<id>/records`. Datasets: `gtfs_routes` (line id, `route_short_name`, `route_long_name`, `route_color` hex without `#`, `shape` = GeoJSON MultiLineString `[lon, lat]`), `lineas-red-fgc` (`route_text_color`), `gtfs_stops` (305 rows; `limit` max is 100, so it is paged with `offset` until a page returns fewer than 100 rows), `codigo-estaciones` (`inicials`, `nom_estacio`, `linia`, `ordre`), `posicionament-dels-trens` (live trains, all values strings). A new `FGCClient` (no credentials, same 10 s timeout as `TMBClient`) and Foundation-only parsers in `TransportCat/Core/FGC/`.
- S2 Network topology. Loaded once per launch: lines with color, text color and polyline; stations with code, name and coordinates. Station code join: a live stop code (e.g. "GR") is `codigo-estaciones.inicials`; its coordinates come from the first `gtfs_stops` row whose `stop_id` equals the code or starts with it ("GR", "GR1"…; all share coordinates). Routes without a shape are kept without a polyline.
- S3 Live trains. Poll `posicionament-dels-trens?limit=100` every 30 s (server refresh measured at ~30 s; daily quota 5000 per client). Each train: `id`, line code, direction `dir`, origin, destination name (from `desti` code via S2), position `geo_point_2d`, next stops parsed from `properes_parades` (semicolon-separated objects `{"parada": "GR"}`), `en_hora` ("True"/"False"), `estacionat_a` (null, "NO" or a stop code), unit type, per-car occupancy percent (may be null). A malformed record is skipped, never fails the poll.
- S4 Line aliases. Live `lin` values not present in `gtfs_routes` map as: `R5R`→`R5`, `R6R`→`R6`, `R61`→`R6`, `R62`→`R6`. Any other unknown code (today `M1`, `M2`) is drawn with neutral gray `8E8E93` and its own code as label. (Assumption to verify with live data: aliases are services of the base line.)
- S5 Smooth motion. Between polls trains glide, never jump: each new GPS point is projected onto the line polyline (`GeoMath.nearestProjection`) and the marker animates along the track from the previous projected distance to the new one over the poll interval, reusing the existing `TrainMotion` approach of the metro. Heading comes from the track direction at the projected point (`GeoMath.bearingDegrees`). A train farther than 300 m from its line's polyline is drawn at its raw GPS point without track snapping.
- S6 Mode. `AppMode` gains `fgc`; `ModeSelector` shows "Metro | Bus | FGC". RootView shows `FGCMapScreen` on Mapa and `FGCLinesScreen` on Línies for that mode, with the same cross-fade as metro/bus.
- S7 Map screen. Same header shape as the metro map: mode selector, line chips (FGC lines from S2 with their colors; selected one persisted), freshness chip (`FreshnessChip(updatedAt:lastAttemptFailed:feedEmpty:)`, 30 s poll so "En directe" stays up to 45 s). Map: selected line polyline in its color, other FGC lines at 25 % opacity, stations of the selected line as markers, trains of the selected line as markers in the line color with the line code and destination, rotated with the heading against the camera like `BusMarker`. Loading uses `MapLoadingPlaceholder`; motion uses `AppMotion`.
- S8 Train sheet. Tapping a train opens a sheet (presented from the NavigationStack, detents medium/large): line badge, "Cap a <destí>", "Puntual" or "Amb retard" from `en_hora`, next stops list (names from S2), "Aturat a <estació>" when `estacionat_a` is a code, and occupancy per car as a small bar row when present ("Ocupació"). "Seguir" button: while on, the camera follows the train (re-centers on each motion update) until the user pans the map or closes the sheet.
- S9 Lines screen (Línies tab in FGC mode). Vertical list of the selected line's stations in `codigo-estaciones.ordre` order, with the trains currently at or heading to each station (from `estacionat_a` and the first `properes_parades` code) shown as small badges with destination. Same line chips and freshness chip as S7.
- S10 Attribution. FGC data is CC-BY 4.0: the map shows a small footer "Dades: FGC · CC BY 4.0" in FGC mode. No FGC incidents chip: FGC publishes no line disruption feed (`avisos` is empty, verified 2026-11-02).
- S11 Shared layer model (for the future global mode). FGC state exposes its drawable content as plain value types in `TransportCat/Core/MapLayer.swift`: `MapLineLayer { id, operator, code, colorHex, textColorHex, polylines: [[GeoPoint]] }` and `MapVehicle { id, lineCode, colorHex, position: GeoPoint, heading: Double, label: String }`. Only FGC adopts them in this feature; metro and bus are not refactored.
- S12 No regression. Metro and bus behavior, text and accessibility labels stay; existing tests keep passing. Persisted `appMode` values "metro" and "bus" still decode.

Out of scope: global mode, Rodalies, notifications, FGC incidents, refactoring metro/bus onto S11.
