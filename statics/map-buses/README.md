# Top-down bus map markers

12 original SVGs and transparent 3× PNG exports: standard, articulated and electric
bus silhouettes in red, blue, green and amber. Colors are illustrative customization
options, NOT official bus line assignments. Electric and articulated variants must
only represent those vehicle types when supported by actual data.

Standard/electric: 54×32; articulated: 64×32. Suggested display width: 36–42 points,
maintaining aspect ratio. The centered anchor is (0.5, 0.5); the windshield and
headlights point east. Rotate the entire marker along the route tangent and keep
labels separate and upright. Position animation belongs to the map, not the SVG.

White body outlines, visible tires, rooftop equipment and a dark windshield distinguish
these buses from the existing trains. Stylized assets, not exact fleet models.
No app integration or live movement is included. Previous train sets are unchanged.
See `preview.png` for dark/light background and small-size comparisons.
