# CatTrans app icon

`cattrans-app-store-1024.png`: 1024×1024, opaque RGB PNG, full square artwork.
Created with the built-in image generation tool; exported to the existing project's
single-image asset-catalog size. The current application icon has not been replaced.
This is a flattened artwork candidate, not an Icon Composer layered document.

Design prompt: Original CatTrans public-transport icon on full-bleed midnight navy.
White route-based T monogram, cyan intersecting route, coral-red accents, station
nodes and a small top-down bus. Crisp geometric design readable at small sizes.
No typography, operator logos, device mockups or pre-rounded outer corners.

Apple integration guidance:
https://developer.apple.com/help/app-store-connect/manage-app-information/add-an-app-icon

Import into the app icon asset catalog and validate in an Xcode archive before
submission. No upload, release validation or App Store submission was performed.
