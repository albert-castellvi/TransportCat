# Set 02 — Top-down articulated trains

11 original SVGs and transparent 3× PNGs (216×96), one per supported line.
A distinct alternative to `../map-trains/`: three connected cars, roof panels,
a tapered directional cab, light accents and white contrast outlines.
Stylized markers, not accurate rolling-stock illustrations or operator logos.

Render at 42×18.67 points; keep the 72:32 aspect ratio. The anchor is the center
(0.5, 0.5), and the cab points east. Rotate the whole marker along the route tangent.
No movement or application integration is included. The existing first set's
motion demo remains unchanged. Colors come from the existing line badge manifest.

`preview.png` compares enlarged and intended-size markers on light and dark maps.
